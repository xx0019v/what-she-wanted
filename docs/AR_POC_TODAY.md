# 📷 本日の実証：印刷ページ AR（page 4・月夜の森）

**目的**：`4.jpg`（月夜の森を少女が歩くページ）を紙に印刷し、iPhoneのカメラで映すと
ページを認識して、**紙面に追従するAR演出**（霧・ホタル・月光・少女周りの空気）が
表示されることを実機で確認する。

認識ターゲット（`forest-page.mind`）は**すでに生成済み**なので、外部ツールは不要です。

---

## 手順は3つだけ

### STEP 1 — 印刷する
- ファイル：**`print/forest-page-a4.pdf`**（A4横・原本比率・切れなし・余白最小）
  - 代替：`print/forest-page-a4.png`
- 推奨：**A4以上・マット紙・大きく・平ら**（光沢紙は反射で認識が落ちます）

### STEP 2 — スマホでHTTPSで開く（カメラは https / localhost のみ）
**方法A（推奨・インストール不要）: Netlify Drop**
1. PCで `npm run build`（`dist/` が生成。`dist/targets/forest-page.mind` は自動で入ります）
2. https://app.netlify.com/drop を開き、**`dist` フォルダをドラッグ&ドロップ**
3. 発行された **`https://…netlify.app`** をiPhoneで開く（QRでも可）。アカウント不要。

**方法B: 同じWi-FiのLAN**
1. Mac で `npm install` → `npm run build` → **`npm run preview:https`**
2. 表示される `https://<MacのIP>:4173/` をiPhoneで開き、証明書警告を承認
   - ※ iOSは自己署名を弾く場合あり。動かなければ方法A。

### STEP 3 — iPhoneで実証
1. URLを開く → **「ARを始める / Begin AR」**
2. カメラ許可を **許可**
3. 印刷ページにカメラを向ける → 認識されると**霧・ホタル・月光**が紙面に重なって追従
4. **精密確認は `?debug=1` を付けて開く**（例：`https://…netlify.app/?debug=1`）
   - STATUS（SEARCHING / FOUND / LOST）、FPS、初回検出ms、再認識回数、解像度、カメラ状態、エラーが左上に出ます
5. 認識しない時は画面下 **「デモ」** で演出だけ確認可能（認識と演出を切り分け）

---

## 合格の目安（実機で確認してほしい点）
- [ ] かざして **2秒以内**に初回認識（`?debug=1` の FIRST FOUND）
- [ ] **30〜60cm** で認識する
- [ ] 正面だけでなく **約20°傾け** ても追従する
- [ ] **10秒以上** 大きくズレずに表示される
- [ ] 一度外して再度かざすと **再認識**（1.5秒以内が目標）
- [ ] カメラを少し動かしても **激しく震えない**
- [ ] AR が **文字や少女から大きくズレない**
- [ ] ページが無い時も **フリーズしない**（SEARCHINGのまま）
- [ ] console error が出ない

満たさない項目があれば、下の記入欄で教えてください。すぐ原因分析→修正→再ビルドします。

## うまくいかない時（早見表）
| 症状 | 対処 |
|---|---|
| カメラが出ない | `https` で開いているか確認（`http://192.168…` は不可）。方法Aへ |
| 認識しない | もっと大きく印刷／マット紙／明るく／30–60cmに近づく |
| 「HTTPS required」表示 | 方法A（Netlify Drop）でhttps URLを発行 |
| iOSでカメラ不可 | Safariで開く。設定→Safari→カメラを許可。自己署名は方法Aで回避 |
| ARがガクつく/重い | 端末が古い場合あり。低性能でも動くよう軽量化済み。結果を教えてください |
| ズレる/震える | フィルタ調整で改善します。`?debug=1` のFPSと合わせて連絡ください |

## いま残っている制約（正直に）
- **実機カメラ挙動（iOS Safariでの認識速度・追従安定性）は、この環境では検証不可**です。
  ビルド・型・Lint・配信（HTTPS 200応答）・ターゲット生成と読み込みまでは確認済みですが、
  「印刷ページを実際に認識してAR追従するか」は**あなたの実機テストが最初の確認**になります。
- 結果を上のテンプレで返していただければ、フィルタ値（filterMinCF/Beta）、ターゲット解像度、
  演出の重さなどを即修正し、合格までループします。
