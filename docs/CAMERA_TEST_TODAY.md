# 📷 実機カメラ実証ガイド（今日やること）

紙に印刷したページを、あなたのスマホのカメラで認識させて `PAGE ALIVE` を起動する
までの最短手順です。所要 約10分。

---

## 全体像（3ステップ）

1. **ページを印刷する** … 認識対象（ターゲット）を物理的に用意
2. **`targets.mind` を作る** … カメラが「どの絵がどのページか」を判別するための認識データ（約1分・ブラウザだけ）
3. **スマホでHTTPSで開く** … カメラは `https` か `localhost` でしか動かない

---

## STEP 1 — ページを印刷する

- ファイル: **`docs/print-targets-A4.pdf`**（A4横・17ページ・各ページ1枚）
- おすすめ設定:
  - **A4以上・できるだけ大きく**（大きいほど認識が安定）
  - **マット紙**（光沢紙は照明の反射で認識が落ちる）
  - 平らに置く／持つ（曲がると精度が下がる）
- まずは強い1〜2枚だけでもOK。**特徴が多く認識しやすい順**の目安:
  **8（部屋）→ 1（表紙）→ 13 → 2 → 14（魔女の顔）→ 11（紫月）**
  ※ 実測では全17ページとも特徴点が十分（ORB 2000/上限）で、基本どれも認識可能です。

---

## STEP 2 — `targets.mind` を作る（ブラウザ・約1分）

MindAR公式のオンライン・コンパイラを使います（インストール不要）。

1. PCで開く → **https://hiukim.github.io/mind-ar-js-doc/tools/compile**
2. `public/pages/` の画像を **必ず番号順（1 → 2 → … → 17）** でドラッグ＆ドロップ
   > ⚠️ 追加した順番が認識インデックスになります。アプリは「1番目＝ページ1」で対応付けているため、**順番厳守**。
   > 全17枚を入れると全ページ対応。まず数枚で試す場合も、**1から連番で**入れてください。
3. **Start** → 数十秒待つ → **Download** で `targets.mind` を取得
4. ダウンロードした `targets.mind` を **`public/targets/targets.mind`** に置く
   （公開ビルドを配る場合は **`dist/targets/targets.mind`** にも同じものを置く）

`targets.mind` が置かれると、アプリは自動でカメラ認識モードになります。
無い場合は「手動でページを選ぶ」フォールバックで動作します（実証には STEP 2 必須）。

---

## STEP 3 — スマホでHTTPSで開く

カメラAPIは安全な文脈（`https` か `localhost`）でしか動きません。スマホ実機では下のどちらか。

### 方法A（最も簡単・推奨）: Netlify Drop で即HTTPS公開
1. PCで `npm run build` → `dist/` が生成される（`targets.mind` を `dist/targets/` に入れておく）
2. **https://app.netlify.com/drop** を開き、**`dist` フォルダをドラッグ＆ドロップ**
3. 発行された **`https://…netlify.app`** をスマホで開く（QRにしても可）
4. アカウント不要。iOS Safari でもカメラが動きます。

### 方法B: 同じWi-FiのLANでHTTPS
1. Mac で **`npm run preview:https`**（先に `npm run build`）
   - 表示される `https://<MacのIP>:4173/` をスマホで開く
   - 自己署名証明書の警告 → 「詳細 → このサイトを開く」で続行
   - ※ iOSは自己署名を弾くことがあります。動かなければ方法Aを使ってください。

> Node/ターミナルが無い場合は **方法A** だけでOK（`dist` を配布用に渡します）。

---

## STEP 4 — 実証する

1. 発行URLをスマホで開く → **START →「ページをかざす」**
2. カメラ許可を **許可**
3. 印刷したページにカメラを向ける → 認識されると **そのページの PAGE ALIVE 演出** が起動
4. 数秒後 **「この世界に入りますか？」→ ENTER** で 360°の森へ
5. うまく認識しない時:
   - もっと近づく／もっと明るく／ページを大きく印刷
   - 画面下「手動で選ぶ」で該当ページを選べば演出は確認できます（認識だけ切り分け）

---

## うまくいかない時のチェック

| 症状 | 対処 |
|---|---|
| カメラが出ない | `https` で開いているか確認（`http://192.168…` はNG）。方法Aへ |
| 認識しない | ページを大きく印刷／マット紙／明るく／近づく。強い順は 8,1,13,2,14 |
| ページ違いで起動 | コンパイラに **1→17の順** で入れ直す（順番が対応表） |
| iOSでカメラ不可 | 自己署名は弾かれる。**Netlify Drop（方法A）**を使う |
| 重い・カクつく | 設定 ⚙ →「軽量」モード |

---

### 補足
- MindAR本体はCDNから実行時読み込み（アプリのビルドには同梱していません）。オフライン時はカメラ認識のみ不可、他は動作します。
- `targets.mind` はこのリポジトリには未同梱（あなたの手元で1分生成）。生成後は差し替えるだけで恒久的に使えます。
